# AIAutomix Architecture

## Vision

Build AIAutomix as a single AI Business Operating System.

## Stack

-   Next.js 15 (App Router)
-   TypeScript
-   Tailwind CSS
-   shadcn/ui
-   Supabase (Auth, PostgreSQL, Storage, pgvector)
-   OpenAI
-   LangGraph
-   n8n
-   Vercel

## Layers

1.  Marketing Website
2.  Authentication
3.  Dashboard
4.  AI Services
5.  Admin Panel

## Folder Structure

    app/
    components/
    features/
    lib/
    hooks/
    types/
    styles/
    public/

## Principles

-   Reusable components
-   Server Components by default
-   Feature-based organization
-   No duplicated UI
-   Clean API boundaries
