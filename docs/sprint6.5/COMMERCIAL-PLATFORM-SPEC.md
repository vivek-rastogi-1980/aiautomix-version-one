# COMMERCIAL PLATFORM SPECIFICATION

## Purpose
Provide the foundation for AIAutomix monetization.

## Commercial Ownership
Workspace is the billing and entitlement boundary.

User → Workspace → Subscription → Entitlements → Usage/Credits

## Core Domains
- Plan Catalog
- Subscription
- Entitlements
- Usage
- Credits
- Pricing

Feature modules must not know payment-provider details.
