# RESEARCH EVIDENCE SPECIFICATION

## Source
URL, canonical URL, title, publisher, source type, publication date, retrieved date and status.

## Evidence
Source reference, finding/claim, evidence reference, confidence, report section and timestamp.

## Rules
- No fabricated sources or quotations.
- External content is untrusted.
- Conflicting evidence must be flagged.
- Missing evidence must be visible.
- Prefer primary/authoritative sources where available.
